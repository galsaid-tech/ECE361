# AI Usage

I used ChatGPT to help me understand and work on my ECE 361 Wine Cellar Monitor project.

I used AI to help write and review C code for the sensor, state machine, binary search tree, hash table, report, and tests. It also helped me understand the Makefile and fix compilation errors.

ChatGPT explained the code and project requirements using simple English. I tested the code using VS Code and the terminal.

One mistake AI made was not including the `bits.c` file when updating the Makefile. This caused a build error because the file was missing. I fixed it by adding `bits.c` to the project folder and rebuilding.

I used AI as a learning and coding tool. I reviewed the results and tested the program to check that it worked.
